# Краткое описание проекта «SANPIN-Schedule»

## 1. Идея проекта

В школе расписание обычно составляет завуч вручную.
Нужно учитывать:

- сколько уроков каждого предмета должно быть в неделю;
- чтобы дети не были перегружены в отдельные дни;
- чтобы тяжёлые предметы (математика и др.) не стояли подряд и не ставились в конце дня.

В проекте «SANPIN-Schedule» мы показываем, как это можно сделать автоматически
с помощью программы на Python.

## 2. Основные принципы

1. **Каждому предмету** мы назначаем "вес" — количество баллов трудности за урок.  
   Например:
   - математика — 4 балла;
   - русский язык — 3 балла;
   - физкультура — 1 балл.

2. **Для каждой ступени обучения** задаём:
   - максимальное число уроков в день (например, не больше 6 в 5 классе);
   - максимальную суточную нагрузку в баллах (например, не больше 20 баллов).

3. Программа автоматически распределяет уроки по дням недели и урокам
   так, чтобы:
   - выполнить учебный план (сколько уроков в неделю по каждому предмету);
   - не выйти за лимит уроков и баллов на день;
   - более сложные предметы приходились на вторник–среду (дни наибольшей работоспособности);
   - понедельник и пятница были полегче.

## 3. Как устроен проект

Структура папок:

- `data/` — входные данные:
  - `subjects.yaml` — предметы и их трудность (баллы);
  - `classes.yaml` — список классов и их численность;
  - `rooms.yaml` — кабинеты и их вместимость;
  - `teachers.yaml` — учителя и их предметы;
  - `sanpin_limits.yaml` — лимиты по урокам и баллам для разных ступеней.

- `src/` — исходный код:
  - `solvers/ortools_solver.py` — алгоритм, который составляет расписание
    (в учебной версии используется простой жадный метод);
  - `cli.py` — запуск из командной строки, создаёт файл `timetable.csv`.

- `tools/`:
  - `generate_timetable_md.py` — скрипт, который читает `timetable.csv`
    и строит красивый файл `timetable.md` с таблицами по классам.

- `notebooks/`:
  - `01_check_daily_load.py` — пример проверки суточной нагрузки по баллам
    для каждого класса и дня недели.

- `tests/`:
  - `test_daily_load_limits.py` — автоматическая проверка, что программа
    не нарушает заданные лимиты.

## 4. Пример результата

После запуска программы мы получаем:

- `timetable.csv` — технический файл с расписанием (для компьютера, открывается в Excel);
- `timetable.md` — человекочитаемый файл с таблицами,
  где по каждому классу видно, какие уроки идут в какие дни и в каком порядке.

Пример строки расписания в CSV:

```text
class_id,day,slot,subject_id
5A,tuesday,1,math

То есть в 5А во вторник на 1-м уроке стоит математика.

5. Значение проекта

Этот проект показывает, что:

школьное расписание можно описать в виде математической задачи;

на языке Python можно написать программу, которая помогает завучу:
не нарушать нагрузку, экономить время и избегать перегрузок;

даже школьный проект может основываться на реальных нормативах
и использовать профессиональные инструменты (YAML, автотесты, генерация отчётов).

# Общий пайплайн планировщика расписания

Ниже показана упрощённая схема того, как данные проходят через систему:
от исходных YAML-файлов до итоговых отчётов по классам и учителям.

```text
+------------------------------+
|  data/*.yaml                 |
|  (subjects, classes,         |
|   rooms, teachers, sanpin)   |
+------------------------------+
              |
              v
+------------------------------+
|  io.loader.load_all_data     |
+------------------------------+
              |
              v
+------------------------------+
|  solvers.ortools_solver      |
|  - недельный план по классам |
|  - СанПиН-баллы по дням      |
|  - жадное назначение учителей|
+------------------------------+
              |
              v
+------------------------------+
|  timetable (in memory)       |
|  список строк:               |
|  class_id, day, slot,        |
|  subject_id, room_id,        |
|  teacher_id                  |
+------------------------------+
              |
              v
+------------------------------+
|  io.exporter.export_timetable|
|  - timetable.csv             |
|  - timetable.md              |
+------------------------------+
      |                    |
      |                    |
      v                    v
+----------------+   +---------------------------+
| scripts/       |   | scripts/                  |
| teacher_load_  |   | class_load_report.py      |
| report.py      |   |                           |
+----------------+   +---------------------------+
      |                    |
      v                    v
+----------------+   +---------------------------+
| Отчёт по       |   | Отчёт по нагрузке классов |
| нагрузке       |   | (СанПиН, баллы по дням)   |
| учителей       |   +---------------------------+
+----------------+
